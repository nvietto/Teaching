# Teaching

This repo contains course material for the classes I have taught.

My lectures are created using Quarto. For a tutorial on Quarto go <a href = "https://quarto.org/docs/get-started/hello/rstudio.html" >here</a>. 

Also, here is a link to a website I created that I use to introduce students to generative art using R in Posit Cloud for extra credit. Posit Cloud is completely free and there are instructions in there with pictures to help students set it up. The students have a lot of fun with this and I do an art show every year before one of our final classes. Feel free to use. Check it out <a href = "https://nvietto.quarto.pub/extra-credit---generative-art/">here<\a>.
