# Teaching

This repo contains course material for the classes I have taught.

My lectures are created using Quarto. For a tutorial on Quarto go <a href = "https://quarto.org/docs/get-started/hello/rstudio.html" >here</a>. 

<a href = "https://nvietto.quarto.pub/extra-credit---generative-art/">Here</a> is a link to a website I created that introduces students to generative art using R in Posit Cloud - something I offer as an extra credit opportunity. Posit Cloud is completely free, and the site includes step-by-step instructions with pictures to help students get set up. They always have a lot of fun with it, and I usually do an art show every year before one of our final classes. Feel free to use it.
